# LawFirmWebsite

Modern, responsive law firm website for **Mallery & Stern - Work Injury Attorneys** (Specializing in California Workers' Compensation since 1976).

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + PostCSS
- **Icons:** Lucide React
- **Routing:** React Router DOM

## Features
- **Two-Tier Navigation Bar:**
  - Tier 1: White header with branded `[M || S]` monogram logo, contact info, and phone callout (`310-473-0777`).
  - Tier 2: Deep Navy (`#0E336B`) navigation bar featuring:
    1. HOME
    2. ABOUT US (dropdown)
    3. OUR SERVICES
    4. Q&A
    5. RESOURCES
    6. CONTACT
    7. BLOG
    8. CLIENT TESTIMONIALS
    9. SOCIAL MEDIA
- **Hero Section:** Marble backdrop, Lady Justice silhouette, curved navy wave cut, and bold headline.
- **Mission & History:** Representing California injured workers across Los Angeles, Riverside, and San Bernardino counties since 1976.
- **"We Are Here For You" Section:** Dedicated worker support and legal consultation details.
- **Practice Areas:** Work Injuries, Wrongful Termination, Wage & Hour Disputes, Serious Bodily Injury Claims.
- **Attorneys & Office Locations:**
  - Los Angeles Office: 5120 West Goldleaf Circle, #380, Los Angeles, CA 90056
  - Rancho Office: 8350 Archibald Avenue, #206, Rancho Cucamonga, CA 91730
  - Super Lawyers 10-Year badge (Lawrence I. Stern)
- **Interactive Free Case Consultation Modal:** Fully responsive modal for confidential claim reviews.
